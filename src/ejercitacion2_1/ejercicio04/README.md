# Ejercicio 04 — Calculadora

**Objetivo:** métodos con parámetros y retorno de tipo primitivo `double`, con control de errores.
**Salida esperada:** suma, resta, multiplicación y división válida; la división por cero avisa y devuelve `0.0`.

**Conceptos:** `return` · clase sin atributos (stateless) · validación de casos límite
