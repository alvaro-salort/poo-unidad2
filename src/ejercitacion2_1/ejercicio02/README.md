**Objetivo:** usar un constructor parametrizado con `this` para inicializar el objeto de forma segura.
**Salida esperada:** cinco mascotas (nombre, especie y edad) alineadas con `printf`.

**Conceptos:** constructor · referencia `this` · `printf` con especificadores (`%-12s`, `%2d`)
